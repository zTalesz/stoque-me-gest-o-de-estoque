# 📦 Stoque.me

Sistema web de gestão de estoque, inventário e vendas desenvolvido em **ASP.NET Core**, **C#**, **SQLite** e **Entity Framework Core**.

Projeto acadêmico desenvolvido para o **Projeto Integrado Multidisciplinar III (PIM III)** do curso de **Análise e Desenvolvimento de Sistemas – UNIP**.

---

## 🚀 Sobre o Projeto

O **Stoque.me** foi criado para auxiliar pequenos comércios, mercados de bairro e lojas de conveniência no gerenciamento de estoque, controle de produtos e acompanhamento de indicadores operacionais.

O sistema busca reduzir perdas por vencimento, melhorar o controle de inventário e fornecer informações estratégicas através de dashboards e relatórios gerenciais.

---

## 🎯 Problema Resolvido

Muitos pequenos estabelecimentos ainda realizam o controle de estoque manualmente, gerando problemas como:

* Produtos vencidos
* Ruptura de estoque
* Falta de rastreabilidade
* Perdas financeiras
* Dificuldade na análise de indicadores

O Stoque.me digitaliza esse processo de forma simples e eficiente.

## ⚙️ Como Executar

### Pré-requisitos

* .NET SDK 8.0 ou superior
* Visual Studio Code ou Visual Studio

### Instalação

```bash
git clone https://github.com/zTalesz/stoque-me.git

cd estoque-me

dotnet restore

dotnet build

dotnet watch run
```

Após iniciar a aplicação, abra a URL exibida no terminal.
